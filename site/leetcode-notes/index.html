Two Pointers

Trigger word: in place on an array (often sorted). If you must rebuild/scan an array using O(1) extra space, two indices do it in one pass.

Two flavours — know which one each problem wants:
① slow / fast (read–write) — both start at the left and move the same direction. fast = read cursor that visits every element; slow = write cursor marking where the next kept element goes. When fast finds a keeper, copy it to slow and bump slow. At the end slow = new length. → remove / dedupe in place.
② opposite ends — one pointer at each end moving toward each other (or filling from the back). → merge / pair-sum on sorted data.
#88 Merge Sorted Array Easy

🔑 Signals two sorted arrays · merge in place into nums1's spare tail opposite ends · from the back

💡 Bite Pointer i at end of nums1's data, j at end of nums2, write cursor k at the very end; copy the larger tail into k and step backwards.

⏱ O(m+n) time · O(1) space

⚠ Trick Fill back-to-front so you never overwrite unmerged nums1 values; leftover nums2 still gets copied.

#27 Remove Element Easy

🔑 Signals remove all val in place · order may change · return new length slow / fast

💡 Bite fast reads every element; when it's a keeper (≠ val) write it at slow and advance slow. slow ends as the new length.

⏱ O(n) time · O(1) space

#26 Remove Duplicates from Sorted Array Easy

🔑 Signals sorted · keep each unique once, in place slow / fast

💡 Bite fast scans; write to slow only when nums[fast] != nums[slow-1] (differs from the last kept value), so duplicates are skipped.

⏱ O(n) time · O(1) space

⚠ Trick "Sorted" is what lets you compare only against the previous kept element instead of a whole set.

#80 Remove Duplicates from Sorted Array II Medium

🔑 Signals sorted · keep each value at most twice, in place slow / fast + look-back

💡 Bite Write nums[fast] to slow only if slow < 2 or it differs from nums[slow-2] — peek 2 back. Generalises to "keep at most k" via slow-k.

⏱ O(n) time · O(1) space

⚠ Trick Compare against nums[slow-2] (the position), not a running count — works only because it's sorted.

Greedy

Trigger words: maximum / minimum, can you reach, "best so far" — and a locally-best choice is provably globally best.

The move: sweep once, keep a single running "best" (min price, farthest reach, running tank…) and make the obvious greedy choice at each step. Never look back, never store the whole history — that's what keeps it O(1) space.
#121 Best Time to Buy and Sell Stock Easy

🔑 Signals one transaction · maximise profit track min-so-far

💡 Bite Sweep once keeping the cheapest price seen on the left; at each day candidate profit = price − minSoFar, keep the max.

⏱ O(n) time · O(1) space

#122 Best Time to Buy and Sell Stock II Medium

🔑 Signals unlimited transactions · maximise profit sum the rises

💡 Bite Add every positive day-to-day delta price[i]−price[i-1] — catching every upward step equals the best multi-trade profit.

⏱ O(n) time · O(1) space

#55 Jump Game Medium

🔑 Signals can you reach the last index? · jump lengths track farthest reach

💡 Bite Sweep keeping maxReach; if an index is beyond maxReach you're stuck → false, else extend reach with i + nums[i].

⏱ O(n) time · O(1) space

#45 Jump Game II Medium

🔑 Signals minimum jumps to reach the end greedy BFS by levels

💡 Bite Each jump is a "level"; track current level's end and the farthest reachable. When i == currentEnd, jumps++ and set currentEnd = farthest.

⏱ O(n) time · O(1) space

⚠ Trick It's implicit BFS — the level boundary is what counts a jump.

#134 Gas Station Medium

🔑 Signals circular route · find the unique start that completes the loop running tank + reset start

💡 Bite If total gas ≥ total cost a start exists; track running tank, and whenever it dips below 0 reset start to the next station and zero the tank.

⏱ O(n) time · O(1) space

⚠ Trick A failing segment can't contain the answer, so the station right after a deficit is the only candidate.

Prefix / Suffix Product

Trigger words: except self / "all elements but this one", or "no division" — each answer needs an aggregate of everything before and after an index.

The move: two sweeps. Pass 1 (L→R) stores the running product of everything to the left; pass 2 (R→L) multiplies in the running product of everything to the right. Left × Right = "all except me".
#238 Product of Array Except Self Medium

🔑 Signals product of all except self · no division · O(n) required prefix × suffix

💡 Bite Pass 1 L→R fills each slot with the product of everything to its left; pass 2 R→L multiplies in everything to its right (held in one scalar).

⏱ O(n) time · O(1) extra space (output reused)

⚠ Trick Division is banned because a single 0 breaks total/nums[i]; prefix/suffix handles zeros for free.

Boyer-Moore Voting

Trigger words: more than n/2 times (strict majority) and a demand for O(1) space (no hashmap).

The move: keep one candidate + a count. Matching element → count++, different → count−−, count hits 0 → adopt the current element as the new candidate. The true majority can never be fully cancelled, so it survives.
#169 Majority Element Easy

🔑 Signals element appearing more than n/2 times · want O(1) space vote & cancel

💡 Bite One candidate + count: same ++ , different −− , adopt new candidate when count==0 — majority outlasts all cancellations.

⏱ O(n) time · O(1) space

⚠ Trick Only valid because a strict majority is guaranteed; a HashMap count is the easy O(n)-space fallback.

Array In-Place Tricks

Trigger words: transform the array in place, O(1) space — reach for reversal tricks, cyclic replacement, or index-as-hash.

#189 Rotate Array Medium

🔑 Signals rotate right by k · in place, O(1) space triple reversal

💡 Bite Reverse the whole array → reverse first k → reverse the rest. Each element lands in its rotated spot.

⏱ O(n) time · O(1) space

⚠ Trick Do k %= n first; reversal avoids the GCD bookkeeping of cyclic swaps.

Sorting / Counting

Trigger words: an order statistic or a threshold over a distribution (k-th, "at least h with ≥ h") — sort then scan, or bucket-count in O(n).

#274 H-Index Medium

🔑 Signals largest h with ≥ h items ≥ h · answer bounded by n counting sort

💡 Bite Bucket citations (clamp > n into bucket n), scan high→low accumulating a running count; first index where running count ≥ index is the answer.

⏱ O(n) time · O(n) space — or O(n log n)/O(1) with sort+scan

⚠ Trick Clamp citations above n — they can't push h beyond n anyway.

Design / Hashing

Trigger words: an API needing O(1) insert + delete + random — pair a hash map (value → index) with a backing array.

The move: the array gives O(1) random pick + O(1) append; the map gives O(1) locate. To delete in O(1) without leaving a hole, swap the target with the last element, pop the last, and fix the moved element's index in the map.
#380 Insert Delete GetRandom O(1) Medium

🔑 Signals insert + delete + getRandom all O(1) array + hashmap(val→idx)

💡 Bite Array for random/append, map for lookup; delete = swap target with last element, pop, and update the moved element's index in the map.

⏱ O(1) average per op · O(n) space

⚠ Trick The swap-with-last on delete is the whole point — and don't forget to repoint the moved element in the map.
